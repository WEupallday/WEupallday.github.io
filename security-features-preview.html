🔐 TheFlap · Security Features

PREVIEW / MOCKUP for approval — nothing here is live. Interactive so you can feel the flows.

This prototype demonstrates three things: (1) logged-in password change, (2) forgot-password reset via an emailed code (with admin-assisted fallback), and (3) linking an email to your account for recovery — plus (4) the admin security log. Verification "emails" are simulated: the code is shown in an orange box so you can complete the flow here.
